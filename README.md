# den

Личный браузер для Android 15 и новее. Открывает мобильный сайт YouTube, ищет видео по тексту из адресной строки и открывает HTTPS-адреса. Поддерживает полноэкранный режим HTML-видео.

Приложение использует системный Android WebView. Единственное разрешение приложения — доступ к интернету. YouTube и другие открытые сайты обрабатывают запросы и сохраняют данные сайта по своим правилам.

## Аккаунт YouTube и панель парковки

- На главном экране den доступны **Главная**, **Подписки** и **Профиль**. Главная показывает свежие видео из подписок, а в подписках можно открыть публикации выбранного канала. В профиле доступны ваш канал, плейлисты и список понравившихся видео, если его предоставил YouTube.
- Поиск и карточки открывают ролики в браузере den. Встроенный сайт доступен через **⋮ → Сайт YouTube**. Для персональных рекомендаций, истории и скачанного на экране den есть переход в официальное приложение YouTube. [YouTube Data API](https://developers.google.com/youtube/data/reference/rest/v3/activities/list)
- При первом подключении подтвердите доступ в системном окне Google. den запоминает аккаунт и дальше использует сохранённый доступ, пока действует разрешение Google. [Авторизация на Android](https://developer.android.com/identity/authorization)
- Парковочный экран принимает ссылки YouTube и поисковые запросы. Коснитесь строки **На парковке**, чтобы показать или скрыть панель. Удерживайте строку, чтобы открыть её настройки.
- Для показа на телефоне выберите **⋮ → Демонстрация на телефоне**. На автомобильном экране в скрытом меню можно убрать надпись **На парковке**, сохранив ограничение Android Auto на движение.
- den запоминает параметры панели и демонстрации. Android может перенести эти настройки из резервной копии или со старого телефона. На новом телефоне подключите аккаунт в разделе **Мой YouTube**. Команда **Забыть аккаунт** удаляет сохранённую привязку с телефона. Управлять разрешением можно в [настройках аккаунта Google](https://myaccount.google.com/connections).

### Регистрация доступа к YouTube

В Google Cloud включите **YouTube Data API v3** и настройте экран согласия Google Auth Platform. Добавьте разрешения `openid`, `https://www.googleapis.com/auth/userinfo.email` и `https://www.googleapis.com/auth/youtube.readonly`. Для личной проверки добавьте свой Google-аккаунт в список тестовых пользователей. Создайте OAuth-клиент типа **Android** для пакета `local.parkbrowser` с SHA-1 сертификата подписанного APK. SHA-1 показывает `apksigner verify --print-certs dist\den.apk`. [Настройка OAuth для YouTube](https://developers.google.com/youtube/data/guides/authentication) · [Регистрация клиента Android](https://developer.android.com/identity/authorization#set-up-your-google-cloud-console-project)

Доступ Google применяется к YouTube Data API. Встроенный сайт и плеер используют собственные правила авторизации и доступности роликов. [Справка Google](https://support.google.com/accounts/answer/16668185?hl=ru)

## Видео с телефона на автомобильном экране

1. На парковке откройте **den** в меню Android Auto.
2. На телефоне выберите ролик в YouTube и нажмите **Поделиться → den**. Если ролик уже открыт в den на телефоне, выберите **⋮ → На экран автомобиля**.
3. Выбранный ролик откроется во встроенном плеере на весь автомобильный экран. Для возврата воспользуйтесь кнопкой **Назад** Android Auto. Если автоматическое воспроизведение заблокировано, нажмите кнопку воспроизведения на плеере.

Если den ещё не открыт в Android Auto, выбранный ролик будет ждать открытия. Встроенный плеер доступен для видео, которые YouTube разрешает встраивать. [Встроенный плеер YouTube](https://developers.google.com/youtube/iframe_api_reference)

На Redmi Note 15 Pro 5G с Android 16 проверено, что в уже подключённом сеансе Android Auto ролик продолжает играть на парковке после блокировки телефона. Проверка выполнена через эмулятор магнитолы Google. Для выбора нового ролика разблокируйте телефон.

## Имитация движения в эмуляторе магнитолы

1. На Windows установите **Android Auto Desktop Head Unit** и **Android SDK Platform-Tools**. На телефоне откройте den, включите сервер головного устройства в меню разработчика Android Auto и подключите разблокированный телефон по USB. [Инструкция Google для подключения через ADB](https://developer.android.com/training/cars/testing/dhu#adb-tunneling)
2. Скачайте `dhu.ps1` из [релиза den](https://github.com/DenAzick/den/releases/latest). Запустите его в PowerShell из папки загрузки. Если путь к эмулятору отличается, укажите свой. Скорость в примере — 15 м/с (54 км/ч).

   ```powershell
   Unblock-File -LiteralPath .\dhu.ps1
   powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File .\dhu.ps1 -DhuPath 'C:\Android\Sdk\extras\google\auto\desktop-head-unit.exe' -SpeedMps 15
   ```

3. На телефоне откройте **den → ⋮ → Снять ограничения в эмуляторе**. Затем откройте den в окне эмулятора и выберите ролик. Снимите отметку в меню, чтобы восстановить ограничения при имитации движения.

Переключатель появляется на время сеанса, запущенного через `dhu.ps1`. Эмулятор начинает тест движения с включёнными ограничениями. Для завершения закройте его окно или нажмите `Ctrl+C` в PowerShell. Команда применяется только к окну Desktop Head Unit, запущенному сценарием. [Команды эмулятора Google](https://developer.android.com/training/cars/testing/dhu#restrictions_and_driving_status)

## Установка на Redmi

1. Откройте `den.apk` из [последнего релиза](https://github.com/DenAzick/den/releases/latest) или папки `dist`. Если телефон запрашивает разрешение на установку, подтвердите его для приложения, в котором открыли APK.
2. Запустите **den**. Приложение готово к работе после первого запуска. Для подключения нового телефона подтвердите настройки Android Auto и включите **Неизвестные источники** в параметрах разработчика Android Auto. [Настройки разработчика Android Auto](https://developer.android.com/training/cars/testing#allow-unknown-sources)

Локальная сборка использует категорию парковочных игр Android Auto (`game`) и отдельную активность `CAR_LAUNCHER`. Android Auto управляет доступом по состоянию автомобиля. Когда парковочный экран останавливается, приложение закрывает WebView и завершает воспроизведение. [Парковочные приложения Android Auto](https://developer.android.com/training/cars/parked/auto)

## Обновления

При запуске на телефоне den сверяется с последним публичным релизом GitHub. Автоматическая проверка выполняется не чаще раза в сутки. Для запуска вручную выберите **⋮ → Проверить обновления**. Для обновления откройте предложенный релиз и подтвердите установку APK в Android.

## Сборка на Windows

Нужны JDK 17, Android SDK Platform 35 и Android SDK Build Tools 35.0.0. При первой сборке Gradle Wrapper скачивает Gradle, плагин Android и зависимости Google Play Services.

```powershell
.\build.ps1
```

В Windows PowerShell 5.1 можно запустить локальный сценарий с настройкой для одного процесса.

```powershell
powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File .\build.ps1
```

Пути к инструментам можно указать явно.

```powershell
.\build.ps1 -SdkPath 'C:\Android\Sdk' -JdkPath 'C:\Java\jdk-17'
```

Сборка создаёт `dist\den.apk` и проверяет подпись. Для обновлений используйте прежний ключ `.signing\parkbrowser.p12` и его пароль в `.signing\password.txt`. При первой сборке создаётся локальная пара файлов для подписи. Файлы подписи предназначены для локального хранения.

Для релиза укажите тег `vX.Y.Z`, соответствующий `versionName` в `app/build.gradle`, увеличьте `versionCode` при выпуске новой версии и добавьте `den.apk` к опубликованному релизу.

Исходный код находится в `app/src/main/java/local/parkbrowser`. Разрешения и точки входа объявлены в `app/src/main/AndroidManifest.xml`.
