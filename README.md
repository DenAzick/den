# den

Личный браузер для Android 15 и новее. Открывает мобильный сайт YouTube, ищет видео по тексту из адресной строки и открывает HTTPS-адреса. Поддерживает полноэкранный режим HTML-видео.

Приложение использует системный Android WebView. Единственное разрешение приложения — доступ к интернету. YouTube и другие открытые сайты обрабатывают запросы и сохраняют данные сайта по своим правилам.

## Аккаунт YouTube и панель парковки

- На телефоне нажмите **⋮ → YouTube с аккаунтом**. Откроются подписки YouTube в браузере телефона. Там можно войти в Google или использовать уже открытую сессию. Встроенный WebView показывает общедоступные страницы в гостевом режиме. [Ограничения входа в Google через WebView](https://support.google.com/accounts/answer/16668185?hl=ru)
- Парковочный экран принимает ссылки YouTube и поисковые запросы. Коснитесь строки **На парковке**, чтобы показать или скрыть панель. Удерживайте строку, чтобы выбрать **Скрывать панель при запуске** или **YouTube с аккаунтом на телефоне**.
- Для показа на телефоне выберите **⋮ → Демонстрация на телефоне**. На автомобильном экране в скрытом меню можно убрать надпись **На парковке**, сохранив ограничение Android Auto на движение.
- den запоминает параметры панели и демонстрации. Android может перенести эти настройки из резервной копии или со старого телефона. Сессия YouTube хранится в обычном браузере телефона и используется при повторном открытии пункта аккаунта.

## Видео с телефона на автомобильном экране

1. На парковке откройте **den** в меню Android Auto.
2. На телефоне выберите ролик в YouTube и нажмите **Поделиться → den**. Если ролик уже открыт в den на телефоне, выберите **⋮ → На экран автомобиля**.
3. Выбранный ролик откроется во встроенном плеере на весь автомобильный экран. Для возврата воспользуйтесь кнопкой **Назад** Android Auto. Если автоматическое воспроизведение заблокировано, нажмите кнопку воспроизведения на плеере.

Если den ещё не открыт в Android Auto, выбранный ролик будет ждать открытия. Встроенный плеер доступен для видео, которые YouTube разрешает встраивать. [Встроенный плеер YouTube](https://developers.google.com/youtube/iframe_api_reference)

## Установка на Redmi

1. Откройте `den.apk` из [последнего релиза](https://github.com/DenAzick/den/releases/latest) или папки `dist`. Если телефон запрашивает разрешение на установку, подтвердите его для приложения, в котором открыли APK.
2. Запустите **den**. Приложение готово к работе после первого запуска. Для подключения нового телефона подтвердите настройки Android Auto и включите **Неизвестные источники** в параметрах разработчика Android Auto. [Настройки разработчика Android Auto](https://developer.android.com/training/cars/testing#allow-unknown-sources)

Локальная сборка использует категорию парковочных игр Android Auto (`game`) и отдельную активность `CAR_LAUNCHER`. Android Auto управляет доступом по состоянию автомобиля. Когда парковочный экран останавливается, приложение закрывает WebView и завершает воспроизведение. [Парковочные приложения Android Auto](https://developer.android.com/training/cars/parked/auto)

## Обновления

При запуске на телефоне den сверяется с последним публичным релизом GitHub. Автоматическая проверка выполняется не чаще раза в сутки. Для запуска вручную выберите **⋮ → Проверить обновления**. Для обновления откройте предложенный релиз и подтвердите установку APK в Android.

## Сборка на Windows

Нужны JDK 17 или новее, Android SDK Platform 35 и Android SDK Build Tools 35.0.0. Сценарий ищет установленные инструменты и работает без Gradle. Сборка с уже установленным SDK не обращается к сети.

```powershell
.\build.ps1
```

В Windows PowerShell 5.1 можно запустить локальный сценарий с настройкой для одного процесса.

```powershell
powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File .\build.ps1
```

Пути к инструментам можно указать явно.

```powershell
.\build.ps1 -SdkPath 'C:\Android\Sdk' -JdkPath 'C:\Java\jdk-17'
```

Сборка создаёт `dist\den.apk` и проверяет подпись. Для обновлений используйте прежний ключ `.signing\parkbrowser.p12` и его пароль в `.signing\password.txt`. При первой сборке создаётся локальная пара файлов для подписи. Файлы подписи предназначены для локального хранения.

Для релиза укажите тег `vX.Y.Z`, соответствующий `versionName` в манифесте, увеличьте `versionCode` при выпуске новой версии и добавьте `den.apk` к опубликованному релизу.

Исходный код находится в `app/src/main/java/local/parkbrowser`. Разрешения и точки входа объявлены в `app/src/main/AndroidManifest.xml`.
